# Z-Day: Último Superviviente

Juego de supervivencia zombi con cámara estilo estrategia en tiempo real. Un solo archivo HTML, sin dependencias.

## Controles
- Clic: mover o atacar a un zombi
- Q granada · W sprint · E vendaje · F comer · G beber
- 1-4 cambiar de arma · R recargar · I mochila · B barricada · N refugio · M silenciar
- En celular: tocá el suelo para moverte y a un zombi para atacarlo; el resto son botones en pantalla. Con la tecla T, en la compu, ves cómo se ve el modo celular.

## Subirlo a GitHub Pages
1. Creá un repositorio nuevo en github.com (por ejemplo `zday`), público.
2. Subí todos los archivos de esta carpeta a la raíz del repositorio con *Add file > Upload files* (incluido `.nojekyll`).
3. Entrá a *Settings > Pages*, elegí *Deploy from a branch*, rama `main` y carpeta `/ (root)`, y guardá.
4. En uno o dos minutos el juego queda en `https://TU-USUARIO.github.io/zday/`.

## Crear el APK
1. Abrí el juego publicado desde el celular, con Chrome, y comprobá que ofrece *Instalar app*.
2. Entrá a https://www.pwabuilder.com, pegá la dirección de GitHub Pages y elegí *Package for stores > Android*.
3. Descargá el paquete, instalá el `.apk` en tu teléfono y probalo.

Recomendación: jugalo con el celular en horizontal. Los botones táctiles ya incluyen mochila, cambio de arma, recarga y construcción.
